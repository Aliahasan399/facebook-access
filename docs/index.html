⚡ One-Click Setup

If you have Hermes Agent installed, just run:

# Clone & run setup
git clone git@github.com:Aliahasan399/facebook-access.git
cd facebook-access
python3 setup.py

📋 What You Need

  1. Hermes Agent — installed and running
  2. Facebook App — create at Meta Developer Portal
  3. Access Token — generated from Graph API Explorer
  4. Live Mode — switch app to Live in settings
